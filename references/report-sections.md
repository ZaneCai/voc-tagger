# HTML 分析报告模块说明

报告是单页 HTML，Chart.js CDN，深色主题（#0d1117），所有数据内嵌。

## 标准模块（按顺序）

### Section 1：总体概况
- KPI 卡片：总评论数 / 平均评分 / 差评率(1-2星) / 好评率(4-5星)
- 星级分布柱状图（颜色：1-2星红，3星灰，4-5星绿）
- 好/中/差评占比甜甜圈图
- 结论文本框（说明关键特征，如邀评影响、差评集中时段）

### Section 2：评分变化趋势
- 双轴折线图：左Y轴月均评分，右Y轴月评论量，X轴时间
- 标注关键节点（上市日期/差评爆发点等）
- 图下结论文字

### Section 3：差评问题地图
- 水平条形图，一级标签按频次排序
- 颜色编码可改善性：红=高（软件/流程可解），橙=中（产品设计），灰=低（硬件/结构性）

### Section 4：问题明细（三级标签 Top20）
- 表格：排名/问题描述/频次/进度条/所属一级/可改善性徽章
- 支持列头点击排序

### Section 5：差评季度分布
- 堆叠柱状图，X轴季度（Q1/Q2等），每色=一级标签
- 图下洞察说明趋势（哪类问题在哪个季度爆发）

### Section 6：优先级矩阵
- 气泡散点图：X轴=频次，Y轴=可改善性(0/1/2)
- 气泡大小=频次，颜色=可改善性
- 四象限标注：重点攻坚/接受规避/快速修复/观察
- hover tooltip 显示详情

### Section 7：行动建议
- 顶部「与现有分析对比」框（如果有研发/测试已做的分析）
- 三列卡片：短期(0-3月)/中期(3-12月)/长期(12月+)
- 每条建议附频次数据支撑

### Section 8：差评分类完整明细
- 三级可展开透视表（点击▶展开L1→L2→L3）
- 每级显示计数 + 迷你进度条（相对父级百分比）
- 颜色延续可改善性编码

## 可选模块

### 市场对比（多市场时）
- US vs JP（或其他市场）并排条形图
- 各市场独特问题 highlight

### 竞品对比
- 如有竞品数据，并排显示差评分类分布差异

## 技术规范

```
背景：#0d1117 / 卡片：#161b22 / 边框：#30363d
文字主：#e6edf3 / 次：#8b949e
红（高可改善/差评）：#f85149
橙（中可改善）：#d29922
灰（低可改善）：#6e7681
绿（好评）：#3fb950
蓝（信息）：#58a6ff
```

**图表高度：** 条形图300px，折线图280px，散点图320-340px
**Canvas包裹：** `<div style="position:relative;height:Xpx"><canvas></canvas></div>`（必须，否则 maintainAspectRatio:false 会导致图表无限拉伸）
**导航栏：** fixed top，48px高，右侧锚点链接跳转各 section
